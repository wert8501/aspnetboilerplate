# 專案結構與程式碼導覽

## 📂 ABP Framework 專案結構概覽

本文件說明 ASP.NET Boilerplate 框架中與 EF Core Repository 相關的程式碼位置，幫助讀者快速定位和理解相關實作。

## 🏗️ 框架核心程式碼結構

### `/src` - 框架核心實作

```
src/
├── Abp/                              # ABP 核心框架
│   ├── Domain/
│   │   └── Repositories/             # Repository 核心抽象
│   │       ├── IRepository.cs       # 基礎 Repository 介面
│   │       ├── IRepositoryOfTEntity.cs
│   │       ├── IRepositoryOfTEntityAndTPrimaryKey.cs
│   │       ├── AbpRepositoryBase.cs  # Repository 基礎實作
│   │       └── ISupportsExplicitLoading.cs
│   │
│   ├── Orm/                          # ORM 抽象層
│   │   ├── ISecondaryOrmRegistrar.cs
│   │   └── NullSecondaryOrmRegistrar.cs
│   │
│   └── Uow/                          # Unit of Work 實作
│       ├── IUnitOfWork.cs
│       ├── UnitOfWorkBase.cs
│       └── UnitOfWorkManager.cs
│
├── Abp.EntityFrameworkCore/          # EF Core 特定實作
│   ├── AbpEntityFrameworkCoreModule.cs  # 模組註冊
│   ├── EfCoreRepositoryBase.cs       # EF Core Repository 基類
│   ├── EfCoreRepositoryBaseOfTEntity.cs
│   ├── EfCoreRepositoryBaseOfTEntityAndTPrimaryKey.cs
│   │
│   ├── Repositories/
│   │   ├── EfCoreRepositoryRegistrar.cs      # Repository 自動註冊
│   │   ├── IRepositoryWithDbContext.cs
│   │   └── IEfCoreRepositoryBase.cs
│   │
│   ├── DbContextProviders/
│   │   ├── IDbContextProvider.cs     # DbContext 提供者介面
│   │   ├── UnitOfWorkDbContextProvider.cs   # UoW DbContext 提供者
│   │   └── DbContextTypeMatcher.cs   # DbContext 類型匹配器
│   │
│   ├── Uow/
│   │   ├── EfCoreUnitOfWork.cs       # EF Core UoW 實作
│   │   ├── IEfCoreTransactionStrategy.cs
│   │   ├── DbContextEfCoreTransactionStrategy.cs
│   │   └── IActiveTransactionProvider.cs
│   │
│   ├── AbpDbContext.cs               # ABP DbContext 基類
│   ├── AbpDbContextOptions.cs
│   └── Extensions/
│       └── AbpEntityFrameworkCoreServiceCollectionExtensions.cs
│
└── Abp.EntityFramework.Common/       # EF 通用功能
    ├── AbpEntityFrameworkCommonModule.cs
    └── DbContextTypeMatcher.cs
```

## 🔍 程式碼學習路徑

### 1. 初學者路徑
1. **Demo 專案開始**: `demo/src/Demo.EntityFrameworkCore/`
2. **基礎測試**: `test/Abp.EntityFrameworkCore.Tests/Tests/Repository_Tests.cs`
3. **核心介面**: `src/Abp/Domain/Repositories/`

### 2. 進階路徑
1. **EF Core 實作**: `src/Abp.EntityFrameworkCore/EfCoreRepositoryBase.cs`
2. **UoW 機制**: `src/Abp.EntityFrameworkCore/Uow/EfCoreUnitOfWork.cs`
3. **自動註冊**: `src/Abp.EntityFrameworkCore/Repositories/EfCoreRepositoryRegistrar.cs`

### 3. 專家路徑
1. **DbContext 提供者**: `src/Abp.EntityFrameworkCore/DbContextProviders/`
2. **交易策略**: `src/Abp.EntityFrameworkCore/Uow/DbContextEfCoreTransactionStrategy.cs`
3. **效能最佳化**: `src/Abp.EntityFrameworkCore/Extensions/`

## 🛠️ 開發環境設置

### 必要工具
- Visual Studio 2022 或 Visual Studio Code
- .NET 6.0 或更高版本
- SQL Server 或其他支援的資料庫

### 推薦擴展/工具
- **Entity Framework Core Power Tools**: EF Core 模型視覺化
- **dotMemory/dotTrace**: 效能分析工具
- **SQL Server Management Studio**: 資料庫管理
- **LINQPad**: LINQ 查詢測試

### 除錯技巧
1. **啟用 EF Core 日誌記錄**:
   ```csharp
   protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
   {
       optionsBuilder.LogTo(Console.WriteLine, LogLevel.Information);
   }
   ```

2. **查看生成的 SQL**:
   ```csharp
   var sql = query.ToQueryString();
   ```

3. **效能分析**:
   ```csharp
   using (var activity = DiagnosticSource.StartActivity("RepositoryOperation", query))
   {
       // Repository 操作
   }
   ```
