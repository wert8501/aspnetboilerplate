## 📋 快速索引

### 🔗 介面速查

| 介面 | 用途 | 關鍵方法 |
|------|------|----------|
| `IRepository` | 基礎標記介面 | - |
| `IRepository<TEntity, TPrimaryKey>` | 泛型Repository核心 | `GetAll()`, `Insert()`, `Update()`, `Delete()` |
| `ISupportsExplicitLoading<TEntity, TPrimaryKey>` | 明確載入支援 | `EnsureCollectionLoaded()`, `EnsurePropertyLoaded()` |
| `IDbContextProvider<TDbContext>` | DbContext提供者 | `GetDbContext()` |

### 🏗️ 核心類別速查

| 類別 | 繼承關係 | 關鍵功能 |
|------|----------|----------|
| `AbpRepositoryBase<TEntity, TPrimaryKey>` | `IRepository<TEntity, TPrimaryKey>` | 基礎Repository實作 |
| `EfCoreRepositoryBase<TDbContext, TEntity, TPrimaryKey>` | `AbpRepositoryBase<TEntity, TPrimaryKey>` | EF Core特定實作 |
| `AbpDbContext` | `DbContext` | 審計、軟刪除、多租戶 |
| `EfCoreUnitOfWork` | `UnitOfWorkBase` | EF Core UoW實作 |

## ⚡ 常用操作速查

### 基本 CRUD 操作

```csharp
// 查詢
var entities = await repository.GetAllListAsync();
var entity = await repository.GetAsync(id);

// 新增
var newEntity = await repository.InsertAsync(entity);
var id = await repository.InsertAndGetIdAsync(entity);

// 更新
var updatedEntity = await repository.UpdateAsync(entity);
await repository.InsertOrUpdateAsync(entity);

// 刪除
await repository.DeleteAsync(id);
await repository.DeleteAsync(entity);
```

### 查詢最佳化

```csharp
// 只讀查詢（無變更追蹤）
var readOnlyEntities = repository.GetAllReadonly();

// 條件查詢
var filteredEntities = repository.GetAll()
    .Where(x => x.Property == value)
    .ToList();

// 包含關聯實體
var entitiesWithNavigation = repository.GetAllIncluding(x => x.NavigationProperty);

// 非同步查詢
var entities = await repository.GetAll()
    .Where(x => x.Property == value)
    .ToListAsync();
```

### Unit of Work 操作

```csharp
// 手動 UoW 管理
using (var uow = unitOfWorkManager.Begin())
{
    // Repository 操作
    await repository.InsertAsync(entity);
    
    // 完成 UoW
    await uow.CompleteAsync();
}

// 交易選項
using (var uow = unitOfWorkManager.Begin(TransactionScopeOption.RequiresNew))
{
    // 需要新交易的操作
    await uow.CompleteAsync();
}
```

## 🛠️ 自訂 Repository 模板

### 介面定義

```csharp
public interface IUserRepository : IRepository<User, long>
{
    Task<User> FindByUsernameAsync(string username);
    Task<List<User>> GetActiveUsersAsync();
    Task<PagedResult<User>> GetUsersPagedAsync(GetUsersInput input);
}
```

### 實作範例

```csharp
public class UserRepository : DemoRepositoryBase<User, long>, IUserRepository
{
    public UserRepository(IDbContextProvider<DemoDbContext> dbContextProvider)
        : base(dbContextProvider)
    {
    }

    public async Task<User> FindByUsernameAsync(string username)
    {
        return await GetAll()
            .FirstOrDefaultAsync(u => u.UserName == username);
    }

    public async Task<List<User>> GetActiveUsersAsync()
    {
        return await GetAll()
            .Where(u => u.IsActive)
            .ToListAsync();
    }

    public async Task<PagedResult<User>> GetUsersPagedAsync(GetUsersInput input)
    {
        var query = GetAll()
            .WhereIf(!input.Filter.IsNullOrWhiteSpace(), 
                u => u.UserName.Contains(input.Filter) || 
                     u.EmailAddress.Contains(input.Filter));

        var totalCount = await query.CountAsync();
        var items = await query
            .OrderBy(input.Sorting ?? "id")
            .PageBy(input)
            .ToListAsync();

        return new PagedResult<User>(totalCount, items);
    }
}
```

## 🧪 測試模板

### 基礎測試類別

```csharp
public abstract class RepositoryTestBase : EntityFrameworkCoreModuleTestBase
{
    protected virtual async Task<T> GetRequiredServiceAsync<T>()
    {
        return GetRequiredService<T>();
    }

    protected virtual async Task WithUnitOfWorkAsync(Func<Task> action)
    {
        using var uow = GetRequiredService<IUnitOfWorkManager>().Begin();
        await action();
        await uow.CompleteAsync();
    }
}
```

### Repository 測試範例

```csharp
public class UserRepository_Tests : RepositoryTestBase
{
    private readonly IUserRepository _userRepository;

    public UserRepository_Tests()
    {
        _userRepository = GetRequiredService<IUserRepository>();
    }

    [Fact]
    public async Task Should_Insert_User()
    {
        await WithUnitOfWorkAsync(async () =>
        {
            // Arrange
            var user = new User
            {
                UserName = "testuser",
                EmailAddress = "test@test.com"
            };

            // Act
            var insertedUser = await _userRepository.InsertAsync(user);

            // Assert
            insertedUser.Id.ShouldBeGreaterThan(0);
            insertedUser.UserName.ShouldBe("testuser");
        });
    }

    [Fact]
    public async Task Should_Find_User_By_Username()
    {
        await WithUnitOfWorkAsync(async () =>
        {
            // Arrange
            await _userRepository.InsertAsync(new User
            {
                UserName = "findme",
                EmailAddress = "findme@test.com"
            });

            // Act
            var user = await _userRepository.FindByUsernameAsync("findme");

            // Assert
            user.ShouldNotBeNull();
            user.UserName.ShouldBe("findme");
        });
    }
}
```

## 🚨 常見問題與解決方案

### Q: Repository 方法返回 IQueryable 還是 List？
**A**: 
- 返回 `IQueryable<T>` 用於可組合查詢
- 返回 `List<T>` 或 `Task<List<T>>` 用於最終結果
- Repository 基類提供兩種方式：`GetAll()` 返回 `IQueryable`，`GetAllListAsync()` 返回 `Task<List<T>>`

### Q: 何時使用自訂 Repository？
**A**:
- 需要複雜的業務查詢邏輯
- 要封裝特定的資料存取模式
- 需要額外的業務規則驗證
- 要提供更語意化的 API

### Q: 如何處理大量資料？
**A**:
- 使用分頁查詢 (`PageBy()`)
- 使用 `AsNoTracking()` 避免變更追蹤
- 考慮使用 `AsAsyncEnumerable()` 進行流式處理
- 批次處理大量插入/更新操作

### Q: 多租戶環境下的注意事項？
**A**:
- Repository 會自動應用租戶過濾器
- 使用 `DisableFilter()` 可臨時停用過濾器
- 注意跨租戶資料存取的安全性
- 測試時要考慮多租戶場景
