# Repository 權威指南

> **針對資深工程師的 ASP.NET Boilerplate Repository 完全實戰手冊**

## 🎯 指南簡介

本權威指南深度探討 ASP.NET Boilerplate 框架中的 Repository 模式實作，特別聚焦於 Entity Framework Core 的企業級應用。內容涵蓋從基礎理論到高級實作的完整技術棧，適合想要深入掌握 Repository 模式的資深工程師。

### 為什麼需要這份指南？

Repository 模式在現代企業級應用中扮演著關鍵角色，它不僅是資料存取的抽象層，更是領域驅動設計、測試驅動開發和微服務架構的重要基石。ASP.NET Boilerplate 提供了一套成熟的 Repository 實作，但其深度功能和企業級特性往往被開發者忽略。

本指南將揭示這些隱藏的寶藏，幫助您：
- 深度理解 Repository 模式的設計哲學
- 掌握 EF Core Repository 的進階技巧
- 實作企業級功能如軟刪除、審計、多租戶
- 建立高效能、可維護的資料存取層
